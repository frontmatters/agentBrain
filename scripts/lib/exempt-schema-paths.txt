# exempt-schema-paths.txt — single source of truth for note-schema exemptions.
#
# Paths listed here are NOT subject to the note-schema invariant (frontmatter
# present, `id:` present, `id` == uuid5-gen(vault-relative path)). They are
# machine-generated buckets, foreign schemas, or raw imported content.
#
# Read by BOTH:
#   - scripts/checks/check-local-content.sh   (the detector)
#   - system/skills/wash-vault/bin/wash-vault (the fixer)
#
# They used to keep separate hand-copied copies that drifted in both
# directions: the detector exempted the core-bench fixtures while the fixer
# did not, so `wash-vault --fix` would have rewritten 79 benchmark files that
# doctor considers healthy. A shared list makes that drift impossible rather
# than something to remember.
#
# Format
#   - one fnmatch glob per line, vault-relative and `local/`-prefixed
#   - `#` at the start of a line is a comment; blank lines are ignored
#   - consumers that work in local/-relative paths must prepend `local/`
#     before matching
#
# This file governs the SCHEMA rules only. wash-vault's rename rule keeps its
# own, deliberately narrower list: filename sanitation is wanted inside
# machine-generated folders, schema validation is not.
