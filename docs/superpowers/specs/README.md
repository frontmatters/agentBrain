# Superpowers — design specs

Validated design documents produced by the `superpowers:brainstorming` skill
(one file per topic: `YYYY-MM-DD-<topic>-design.md`). A spec is the approved
design that a plan in `../plans/` then implements task-by-task.

Tool-managed engineering artifacts, not agentBrain vault notes — no note
frontmatter (exempted in `scripts/check-frontmatter.sh`).
