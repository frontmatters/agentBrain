# Superpowers — implementation plans

Concrete, task-by-task implementation plans produced by the `superpowers:writing-plans`
skill and executed with `superpowers:subagent-driven-development`.

Each file is one plan (`YYYY-MM-DD-<feature>.md`): a goal, an architecture note, a file
map, and bite-sized TDD tasks with exact code, commands, and commit messages.

These are tool-managed engineering artifacts, not agentBrain vault notes — they carry no
note frontmatter (exempted in `scripts/check-frontmatter.sh`).
