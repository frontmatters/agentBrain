# explainers

Shared assets for the brain-explain skill — the themes, copy rules, and norms that turn an agentBrain note into a themed, self-contained HTML explainer.

- `themes/` — swappable explainer themes (one source note, many looks)
- `copy-norms.md` — the explainer copy system (derived from ASD-STE100 / Simplified Technical English): mechanical, self-verifiable rules for all visible copy
- `norm.css` — baseline CSS norms shared across themes
- `categories.txt` — explainer category vocabulary

See the `brain-explain` skill for how these are consumed when rendering or creating a theme.
