# Changelog

All notable changes to this addon are documented in this file.

## [0.1.2] - 2026-09-11

### Changed

- The usage example no longer carries a real address and a real repository
  name. An example is read as a template, so a maintainer's own address in one
  is both a needless disclosure and a line people copy verbatim.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this addon adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).
