# component-motion

Add scroll-driven, staggered, magnetic, and physics motion to web UIs — GSAP ScrollTrigger, smooth scroll (Lenis/Locomotive), scroll-reveal (AOS), anime.js, Motion (Framer), Lottie, and Rive.

Use it whenever the user wants to animate a page or component, add parallax / pinning / reveals / hover or magnetic effects, "make it feel alive", or bring award-site (Awwwards) motion — even without naming a library. Animates web components through their clean seams (host, CSS-variable tokens, `::part`) and always honours `prefers-reduced-motion`. Standalone; pairs with [[technique-transplant]].

The per-library recipes live in `references/` (vendored + sanitized — see that folder's README for provenance). The orchestrator, the seams contract, and the a11y guardrails are agentBrain-authored.

See `SKILL.md` for the full selection guide and per-library procedures.
