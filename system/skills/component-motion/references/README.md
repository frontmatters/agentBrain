# component-motion — references

Per-library motion recipes used by the [[component-motion]] skill. Each doc carries its own `name`/`description` header and is loaded on demand by the orchestrator in `../SKILL.md`.

- `animejs` — anime.js timelines, stagger, SVG morphing
- `gsap-scrolltrigger` — GSAP ScrollTrigger pinning, scrub, parallax
- `lottie` — Lottie/Bodymovin JSON animations
- `motion-for-react` — Motion (Framer Motion) for React
- `rive` — Rive interactive state-machine animations
- `scroll-reveal` — lightweight scroll-reveal (AOS-style)
- `smooth-scroll` — Lenis / Locomotive smooth scrolling

**Provenance:** the recipe markdown is vendored + sanitized (2026-07-27) from `freshtechbro/claudedesignskills` (recipe content only — no scripts, eval, or install-hooks carried over). Owned and maintained here, not a live upstream dependency.
