# cro-optimize

Conversion-rate optimization for landing, marketing, and product pages: benefit-led CTAs, social proof, trust microcopy, incentives, objection-handling FAQ, form/funnel design, A/B testing, and statistical significance.

Use it whenever the user wants to improve conversions, lift signups/sales, optimize a landing or pricing page, reduce friction/bounce, add trust or social proof, or asks "why isn't this converting" — even without saying "CRO". Applies accessibility-safe patterns, on the principle that a11y and conversion are allies, not opposites.

Topic playbooks live in `references/` (vendored + sanitized — see that folder's README for provenance).

See `SKILL.md` for the full method and the a11y × CRO principle.
