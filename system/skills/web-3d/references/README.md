# web-3d — references

Per-engine 3D recipes used by the [[web-3d]] skill, loaded on demand by `../SKILL.md`.

- `three-js` — Three.js core WebGL
- `react-three-fiber` — React renderer for Three.js
- `babylon-js` — Babylon.js engine
- `playcanvas` — PlayCanvas engine
- `pixi-2d` — PixiJS GPU-accelerated 2D
- `spline-nocode` — Spline no-code 3D
- `aframe-webxr` — A-Frame VR/AR (WebXR)
- `lightweight-effects` — cheap decorative 3D without a full engine
- `integration-patterns` — mounting, resizing, cleanup, and non-3D fallbacks

**Provenance:** the per-engine recipes are vendored + sanitized (2026-07-27) from `freshtechbro/claudedesignskills` (recipe markdown only; scaffolding scripts were not carried over). Selection guidance and guardrails are agentBrain-authored. Owned and maintained here.
