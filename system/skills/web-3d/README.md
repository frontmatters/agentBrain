# web-3d

Build 3D / WebGL / WebGPU / WebXR experiences on the web — Three.js, React Three Fiber, Babylon.js, PlayCanvas, PixiJS (2D-GPU), Spline (no-code), and A-Frame (VR/AR), plus lightweight decorative 3D.

Use it whenever the user wants a 3D scene, a product viewer/configurator, particles, a WebGL background, an immersive or VR/AR experience, "add depth / a 3D element", or asks which 3D engine to pick. Heavy and opt-in: prefer lightweight effects for decoration and always ship a non-3D fallback. Pairs with [[component-motion]] and [[technique-transplant]].

Per-engine recipes live in `references/` (vendored + sanitized — see that folder's README for provenance).

See `SKILL.md` for engine-selection guidance and the performance/a11y guardrails.
