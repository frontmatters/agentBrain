# gaplog

Start or maintain a **gaplog**: the register of what already looks built but does not do
what it promises.

A backlog collects what we intend to build. A gaplog collects broken promises, and that
difference decides the burden of proof: every row carries where it plays, who found it,
evidence, and a verification date.

Start one with:

```bash
bash scripts/new-note.sh gaplog vault/projects/<slug>/gaplog "<Project> gaplog"
```

Full procedure, the routing test for border cases, and the anti-patterns: `SKILL.md`.
