# technique-transplant

Harvest a reference website's design + motion *technique* — composition, section rhythm, hero, card/mockup anatomy, scroll choreography — and re-apply it onto the user's own components, without cloning the site's content.

Use it whenever the user wants to "make it look/feel like `<site>`", borrow a competitor's or award-site (Awwwards, Revolut, Stripe, Linear, GSAP-heavy) layout or motion, "apply that technique to our components", or redesign in the style of X — even without saying "harvest" or "technique". Standalone: works with zero other skills, and opportunistically uses harvest / sitescope / uxray / frontend-design when they are installed. Related: [[hallmark]].

See `SKILL.md` for the harvest → distil → transplant procedure.
